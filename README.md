# 📊 Fundamentos de Big Data e Data Analytics em Python

Repositório desenvolvido durante meus estudos em **Big Data e Data Analytics** realizado pelo **SENAI**, reunindo exercícios, análises exploratórias de dados, tratamento de arquivos e projetos realizados ao longo do curso.

O objetivo deste repositório é documentar minha evolução na manipulação e análise de grandes volumes de dados e servir como **portfólio dos conhecimentos adquiridos** na área de dados.

---

## 📚 Conteúdos Estudados

Durante o curso, foram abordados conceitos fundamentais e práticas de análise e engenharia de dados em Python, incluindo:

* 📊 Fundamentos de Big Data e arquitetura de dados
* 📋 Manipulação de dados estruturados com arquivos CSV e JSON
* 🔢 Vetorização e operações matemáticas com **NumPy**
* 🐼 Limpeza, tratamento e filtragem de dados com **Pandas**
* 🔍 Identificação e tratamento de valores nulos (`isnull()`, `fillna()`, `dropna()`)
* ✂️ Fatiamento de dados e uso de máscaras booleanas no NumPy e Pandas
* 📊 Estatística descritiva (médias, medianas, contagens e valores máximos/mínimos)
* 📉 Visualização de dados e gráficos analíticos
* 🧠 Resolução de problemas reais de negócios orientados a dados
* 💻 Desenvolvimento de scripts analíticos práticos
